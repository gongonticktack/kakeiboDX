# Kakeibo DX

This local household budget app imports credit-card PDF statements, stores spending data in PostgreSQL, and visualizes monthly and yearly category trends.

It helps users understand household expenses, spot category patterns, and review personal finance over time.

クレジットカードの利用明細PDFを取り込み、PostgreSQLへ保存して支出を見える化するローカルWeb家計簿です。Python / Flask を主体にしており、グラフや明細一覧で支出の傾向を確認できます。
